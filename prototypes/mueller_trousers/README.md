# Прототип брюк по Мюллер и сын

Это **standalone Python-прототип**, не tool MCP и не production-система
проектирования. Он строит параметрический базовый блок женских классических
брюк по мотивам опубликованной методики М. Мюллер и сын и выдает:

- `*.dxf` — стандартный DXF R12, мм, замкнутые полилинии деталей + насечки и
  направление нити;
- `*.json` — полные данные прототипа (мерки, точки в см, края, насечки,
  grainline, план швов).

Методика реализована как **core-пропорции + полилинейная аппроксимация кривых**.
Это не копия книги и не сертифицированный лекальный блок. Отличия от полного
чертежа перечислены ниже.

## Что строится

- `FRONT_L`, `BACK_L` — передняя и задняя половинки левой ноги;
- `FRONT_R`, `BACK_R` — их зеркальные копии для правой ноги;
- `WAISTBAND` — прямой пояс.

Итого 5 деталей. В DXF все координаты в **мм**, в JSON — в **см** (исходный
чертеж). Контур — **линия шва без припуска**.

## Мерки

Используются половинные обхваты, как в методике:

| Поле | Смысл | Size 40 |
|---|---|---:|
| `waist_half` | Ст, полуобхват талии | 38.0 |
| `hip_half` | Сб, полуобхват бедер | 50.0 |
| `side_length` | Дсб, длина сбоку от талии до пола | 106.0 |
| `seat_height` | Вс, высота сидения | 26.5 |
| `knee_half` | Шк, полуобхват колена | 24.0 |
| `hem_half` | Шн, полуобхват низа | 21.0 |
| `waist_ease` | Пт, прибавка по талии | 1.0 |
| `front_dart` | раствор передней вытачки | 2.0 |
| `back_dart` | раствор задней вытачки | 3.0 |

Ключевые формулы:

```text
y_hip       = Вс - (Сб/10 + 3)
front_hip   = Сб/2 - 1
step        = Сб/10 + 1
front_waist = Ст/2 + front_dart + Пт/2
back_waist  = Ст/2 + back_dart  + Пт/2
knee_height = Дш/2 - Дш/10,  Дш = Дсб - Вс
knee_front  = Шк/2 - 1
hem_front   = Шн/2 - 1
```

## Запуск

Из корня репозитория:

```powershell
python -m prototypes.mueller_trousers --size 40 --out out/trousers_40.dxf
```

Или из каталога `prototypes`:

```powershell
python -m mueller_trousers --size 40 --out out/trousers_40.dxf
```

Свои мерки:

```powershell
python -m prototypes.mueller_trousers --size 40 `
  --waist-half 37 --hip-half 49 --side-length 105 --seat-height 26 `
  --knee-half 23 --hem-half 20 --out out/trousers_custom.dxf
```

Файлы:

- `measurements.py` — мерки, derived-формулы, size presets 36–44;
- `geometry.py` — 2D-хелперы, Безье, площадь, проверка простого полигона;
- `draft.py` — построение 4 половинок и пояса, насечки, grainline, план швов;
- `dxf.py` — DXF R12 writer + JSON sidecar;
- `clo_json.py` — CLO pattern JSON; side/inseam кромки каждой ноги
  экспортируются одной `Polyline`-линией (промежуточные точки), остальные
  линии — обычные сегменты;
- `seam_plan.py` — декомпозиция экспортированных CLO seam groups в per-line
  пары, конвертация perimeter-долей в line-relative ratios и валидатор;
  `--curve-target` переводит план на merged-edge топологию (38 пар);
- `__main__.py` — CLI.

## Curve edges

`clo_json.py` объединяет `side` и `inseam` каждой из четырёх ног в одну линию:
`FRONT_*` 15 линий, `BACK_*` 18, `WAISTBAND` 4. Промежуточные точки получают
`PointType: "Polyline"`, концы — `Straight`. Это даёт один seam-вызов на
кромку вместо 10–12. Длина side-кромки меняется на ~1.4 мм (curve
interpolation), inseam — на ~0.1 мм; проверять после импорта.

Насечки на merged-кромках больше не отдельные точки линии: они теряются как
насечки, но остаются в геометрии как Polyline-вершины. Это осознанный
компромисс прототипа.

## Импорт в CLO

1. CLO → 2D Pattern → Import DXF. Выбрать **Standard DXF**, не AAMA.
2. Ожидается 5 деталей: `FRONT_L`, `BACK_L`, `FRONT_R`, `BACK_R`, `WAISTBAND`.
3. Нота: DXF не AAMA, поэтому native notch/grain semantics не гарантированы.
   Насечки в файле — короткие линии на слое `NOTCH`, grainline — на `GRAIN`.
   Если CLO их не распознала как native, это известное ограничение прототипа.
4. Проверить в 2D: контуры замкнуты, детали не пересекаются, масштаб мм.
5. При необходимости добавить припуск средствами CLO; DXF содержит линию шва.
6. Посадить детали на аватар через arrangement points и сшить. Готовый план:
   `python -m prototypes.mueller_trousers.seam_plan export.json
   --reference-names --curve-target --olga-target --out seam_plan.json`.
   `--curve-target` даёт 38 пар (4 leg whole-line + center/darts/waistband);
   без него — 80 per-line пар для polyline-топологии. Reference `LengthParam`
   напрямую в API не подавать. Вытачки и self-seam пояса —
   `add_seamline_pair_partial` с ratios 0..1: whole-line tool отклоняет
   одинаковые pattern indices.
7. Сначала 2 боковых и 2 шаговых шва, затем центр, затем пояс; после каждого
   шва — readback и скриншот. `import_pattern_json` переносит детали, но не
   швы (`seam_count_after=0`), поэтому швы добавляются отдельными вызовами.
   Полная сборка — отдельный real gate.

## Ограничения прототипа

- Нет полного чертежа Мюллера: задняя талия/средний шов и пояс упрощены;
  кривые — короткие полилинии, а не лекальные дуги.
- Нет fly/гульфика, карманов, шлёвок, подкладки, припусков и градации.
- Нет AAMA/ASTM: CLO может импортировать как Standard DXF; native notches
  могут потребовать AAMA-writer.
- Нет проверки посадки на аватаре: это следующий real gate, не заявление.
- Числа — прототипные; для реального изделия нужна примерка/корректировка.

## Следующие шаги

1. Импортировать `trousers_40.dxf` в CLO, проверить 5 деталей и масштаб.
2. Сшить на копиях/расходной сцене: 2 side + 2 inseam, проверить seam_count.
3. Посадить на аватар, simulate 60, 3D-скриншот; зафиксировать дефекты.
4. Если DXF теряет насечки — добавить AAMA-writer или pattern JSON route.
5. После стабильного импорта — параметрические пресеты и сравнение с мерками.
