# Навыки и правила агента

## Что установлено

Общие ограничения проекта находятся в корневом `AGENTS.md`.
Подробные инструкции загружаются по задаче из `.opencode/skills/`:

- `clo-python-runtime` — Python внутри CLO, callback, UI-поток и запуск.
- `windows-named-pipe` — ctypes, Win32 IPC, протокол и освобождение ресурсов.
- `python-mcp-session` — официальный FastMCP, HTTP, очередь и жизнь сеанса.
- `transport-verification` — диагностика, автоматические тесты и испытания в CLO.

Это локальные текстовые навыки проекта. Они не устанавливают зависимости,
не запускают скрипты и не добавляют инструменты доступа к системе.
Не изменены глобальные настройки, модель, разрешения или политика делегирования.
Навыки не являются подтверждением старта фаз из плана разработки.

OpenCode обнаруживает `.opencode/skills/<id>/SKILL.md` автоматически.
Отдельный opencode.json для этого не требуется. Если интерфейс не обновил
каталог, используйте `/reload`; перезапуск фонового сервиса не нужен.
Проверено в текущем сеансе: OpenCode обнаружил все четыре навыка;
`transport-verification` успешно загружен через skill tool.
Для других клиентов автоматическая загрузка отдельно не проверялась.
Если skill tool пока не видит ID, агент читает соответствующий файл напрямую.

## Подбор и источники

Инструкции написаны специально для этого репозитория, не скопированы из
стороннего набора и не требуют дополнительных лицензионных файлов.

Рассмотрен `anthropics/skills`, навык `mcp-builder`, ревизия
`ca45fc496a3436251f191354091d557da31c15b5` (Apache-2.0):
https://github.com/anthropics/skills/tree/ca45fc496a3436251f191354091d557da31c15b5/skills/mcp-builder

Не установлен целиком: его предпочтения TypeScript, широкий охват API и примеры
для текущих SDK не соответствуют нашему ограниченному Python MVP с MCP 1.26.0.
Не запускались сторонние установщики или скрипты. Вместо общего навыка создан
`python-mcp-session` с конкретными ограничениями проекта.

Специфический Win32/CLO-код требует версионных первоисточников и реальных
испытаний, а не обещания совместимости из общего каталога навыков.

Проверенные источники для структуры инструкций:
- https://opencode.ai/docs/skills
- https://opencode.ai/docs/config

Технические первоисточники перечислены в соответствующих SKILL.md; сверять их
при реализации, не воспринимать ссылки как уже выполненную проверку API.

## Сопровождение

Обновлять правила при согласованном изменении архитектуры. Не добавлять в
постоянный контекст длинные общие учебники, все навыки сразу или инструкции
по неиспользуемым стекам. Хранить факты об испытаниях в плане/отчётах, не выдавать
исторический baseline за неизменное число тестов.
